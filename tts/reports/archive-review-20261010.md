기존 first-audio-ab / first-audio-short-chunk 보고서는 다른 baseline·후보 단계이므로 이 네 자료의 대체본이 아니다.

공개본에는 실제 세션 ID를 `<redacted-session-id>`로 가리고 로컬 사용자 홈 경로를 `~/`로 표기했다. 원본은 로컬 영구 백업의 `report-originals/`에 별도로 보존했다. 측정 값·실험 판정은 변경하지 않았다. JSON 8개 그룹의 표본 수, min/max, median/mean, nearest-rank p90/p95와 receipt 개수를 재검산했다. 일반적인 API 키·Bearer 토큰·개인 키 패턴은 발견되지 않았다. 실제 음성·원본 로그·상태 폴더는 이번 커밋에 포함하지 않는다.

일부 문서의 원시 증거 경로는 실험 당시 로컬 위치이며 저장소에 포함된 파일이 아니다. 해당 원시 증거를 모두 재실행하거나 주관적 청취 결과를 재검증한 것은 아니다.
